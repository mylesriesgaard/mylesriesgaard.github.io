Ruby Schweitzer Portfolio Site | Design Process

Overview

A custom portfolio website for a filmmaker whose work spans cinematography, dance collaborations, experimental film, and graphic design. The goal was to create a cohesive, visually driven experience that showcases her multidisciplinary practice while keeping the focus on the work itself.

Design & Development

Designed and built from scratch, primarily using HTML and CSS, with JavaScript elements supporting interactive slideshows and full-screen image galleries. Some of the more key design decisions of this project include:

· Reel-first landing page: Feature her DoP reel as the sole element on the homepage, immediately showing visitors her work.
· Galleries: Incorporate slideshows and full-screen image viewing to allow users to review individual projects closer.
· Minimal visual approach: Keep the interface simple and unobtrusive, allowing the imagery and film to be the main focus.
